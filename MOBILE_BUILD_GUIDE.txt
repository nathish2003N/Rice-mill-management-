RICE MILL MANAGER - MOBILE CLOUD BUILD

1. Extract this ZIP on your Android phone using Files / File Manager.
2. In Chrome, sign in to GitHub and create a NEW repository named rice-mill-manager.
3. In the repository, use Add file > Upload files. Upload the extracted project contents, keeping folders (lib and .github) and files in the repository root. Do not upload the ZIP alone.
4. Commit the upload to the main branch.
5. Open the repository's Actions tab. Select "Build Android APK" and tap "Run workflow" if it has not started automatically.
6. Wait for the run to finish with a green check. Open that run, scroll to Artifacts, and download rice-mill-manager-apk.
7. Extract the downloaded artifact ZIP and install app-release.apk. Android may ask you to allow installs from Chrome/Files.

NOTES:
- This is a development build starter, not a finished audited accounting system.
- Data is stored locally on the phone; cloud backup/sync is not included.
- Test with sample transactions before using for real accounts.
